CORE GAME LOOP — CURRENTLY IN GAME
1. Player goes 10-41 / in service.
2. Dispatch assigns a call.
3. Player accepts the call with 10-76.
4. Player travels to the correct location.
5. Player marks 10-97 / on scene.
6. Player contacts the involved person.
7. MDT updates with call-specific notes.
8. Player clears the call with 10-8.
9. Player receives Performance XP.
10. Another call can be assigned.
11. Player can go 10-42 / out of service.
12. Shift only counts if the player cleared at least one call.

PROGRESSION DESIGN — CURRENT DIRECTION
Performance XP is not a normal video game level system. It represents experience, performance, and career progress. It helps the player become eligible for promotion, but promotion is not automatic.

Current promotion eligibility requirements shown in the Career tab:
- Performance XP
- Calls cleared
- Shifts completed

Future promotion requirements should include:
- Supervisor review
- Discipline history
- Time-in-rank
- Special assignments
- Promotion board
- Performance record

CURRENT RANK SYSTEM
Current rank starts as Officer. Higher ranks are not implemented yet.

MDT DESIGN — CURRENTLY IN GAME
The MDT is now designed as a laptop/patrol computer interface. It opens with M, locks player movement, shows the mouse cursor, and has clickable tabs.

Current MDT tabs:
- Calls
- Career
